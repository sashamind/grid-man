# Grid Man

Интерактивная сетка с человечком. Одна страница, без зависимостей и сборки —
чистый `index.html` (Canvas + JS), готова к публикации на GitHub Pages.

## Что умеет

- **Линии сетки** можно перетаскивать (вертикальные — влево/вправо, горизонтальные — вверх/вниз).
- **5 точек** (голова, две ладони, две ступни) примагничены к линиям сетки:
  каждая скользит вдоль ближайшей линии **внутри своей ячейки** и
  перекидывается на перпендикулярную линию, если та ближе. За пределы ячейки точка не выходит.
- **Скелет человечка** (позвоночник, руки, ноги) пересчитывается автоматически
  от положения точек и линий.
- Кнопка **Сброс** возвращает исходную расстановку.
- Работает и мышью, и на тач-экранах.

## Локальный запуск

Просто откройте `index.html` в браузере. Сборка не нужна.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и запушьте файлы:
   ```bash
   git init
   git add .
   git commit -m "Grid Man"
   git branch -M main
   git remote add origin https://github.com/<user>/<repo>.git
   git push -u origin main
   ```
2. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)`, **Save**.
3. Через минуту сайт будет доступен по адресу
   `https://<user>.github.io/<repo>/`.
